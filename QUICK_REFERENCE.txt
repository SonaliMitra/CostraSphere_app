❌ "Cannot GET /"
   → Make sure you're on http://localhost:5173 (not 8000)
   → Both servers must be running

❌ "Connection refused"
   → Backend not running. Start: cd backend && python main.py

❌ "Port already in use"
   → Kill process: lsof -ti:8000 | xargs kill -9 (Mac/Linux)
   → Or: netstat -ano | findstr :8000 → taskkill /PID <PID> /F (Windows)

❌ "Module not found"
   → Install deps: pip install -r requirements.txt

❌ Login fails
   → Check backend is running: http://localhost:8000/docs
   → Try exact credentials: developer@costrasphere.ai / CostraSphere@Dev2026

❌ Database error
   → Delete: rm backend/database/costrasphere.db
   → Restart backend - it will recreate automatically
